## Set up.

By default, MightyBot will only run when you tell her to.

I made it to where it can boot on launch.
Later, I will make shell commands to make it run whenever you want it to.

I also recommend installing `requirements.txt'.
For terminal packages, they can be installed if it finds out you don't have the packages

I am running this on Debian Based Linux, so stuff are formatted for that.

## Navigation

The main hub can find the most important info for requirements and running MightyBot
It also features 'mightyfakecode.txt' which will always indicate what I want to work on next.

'mainmighty.py' is the script that runs the discord bot, reading from 'commands'

'commands' is a directory showing all the commands code as well as each commands in detail.

'APIs' shows the code for creating and getting Internal and External APIs and data
